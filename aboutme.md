I’m a software engineer with 10+ years of experience building backend, automation, data, and network-operations software—and today I apply that engineering foundation to agentic AI and software engineering research.

My career began in telecommunications, where I developed workflow automation and network-testing systems for AT&T services. At Tech Mahindra, I worked across Java, Spring, REST, SOAP, microservices, Kafka, Redis, databases, and Python automation. I later moved into data engineering at Bitwise, working with Java, Spark, Python, AWS, and ETL systems, where I investigated and resolved a critical concurrency issue in an AWS S3 component. At Amdocs, I worked on a 5G network automation platform, developing provisioning and inventory workflows while helping refactor legacy systems to achieve 80%+ test coverage and reduce technical debt.

These experiences shaped how I approach engineering: understand complex systems, find failure modes, automate repetitive work, and build software that can be tested and trusted.

Today, as an independent contractor working on agentic software engineering research, I use that background to design and build rigorous environments for evaluating frontier AI models acting as autonomous software engineers. I create complex programming defects, feature requirements, and multi-layered engineering scenarios designed to surface weaknesses in reasoning, tool use, and instruction following. My work spans Java, Spring Boot, microservices, Python, SQL, Docker, Docker Compose, Git, and Bash, alongside agentic coding tools such as Claude Code, Gemini-CLI, Codex, OpenCode, and OpenClaw.

I’m particularly interested in the intersection of software engineering, AI agents, developer tooling, evaluation, and reliable autonomous systems—especially the question of how we can rigorously measure what AI coding agents can actually do, where they fail, and how engineering practices can make them more dependable.

I’m currently pursuing an M.S. in Computer Science (Artificial Intelligence) at Georgia Tech, building on my industry experience with continued work in algorithms, programming, and AI.

Core strengths:
Java • Python • SQL • Spring Boot • Microservices • REST/SOAP • AWS • Docker • Databases • Automation • Software Testing • AI Agent Evaluation • Agentic Coding Tools • Git/Linux/Bash

What I bring: a combination of hands-on software engineering experience, systems thinking, debugging and automation skills, and a growing specialization in agentic AI.
